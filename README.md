# 金融智能运维项目实战

> 从需求调研到 POC 与交付 · 12 篇系列文章 + 5 张原创图示

本系列以金融行业智能运维项目为主线，按项目推进顺序完整走一遍售前到交付的全过程：首次交流、需求调研、范围确定、可行性核查、方案编写、工作量估算、POC 设计与执行、POC 报告、技术承诺确认、售前交接、验收与复盘。

**在线阅读**：<https://xxsai.icu/articles/aiops-practice/>
